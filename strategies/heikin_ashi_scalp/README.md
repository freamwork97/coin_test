# 하이킨아시 5분봉 단타 전략

유튜브 '하이킨아시 5분봉 단타매매법'(차트 승부사 고니) 영상 분석을 코드로 구현한
단기 추세추종 전략. 영상 화면(차트 설정·캔들 해석·매매 구간)을 직접 캡처해
지표 설정값을 확인하고 규칙화했다.

> ⚠️ 연구·학습용 코드다. 실매매 판단과 책임은 본인에게 있다.

## 전략 요약

| 구성 | 설정 |
|---|---|
| 차트 종류 | 하이킨아시 (트레이딩뷰 차트 타입) |
| EMA 20 (빨강) | 눌림목 판단 기준선 |
| EMA 10 (파랑) | 단기 추세선. 10/20 더블 이동평균선 결합 |
| 타임프레임 | 5분봉 |

- EMA는 트레이딩뷰 동작과 동일하게 **하이킨아시 종가 기준**으로 계산
- 진입/손절/익절 가격은 **실제 호가 기준**

## 매매 규칙

**진입 A — 20EMA 눌림목 매수 (주 전략)**
1. 10EMA > 20EMA (상승 정배열)
2. 최근 10봉 안에 20EMA 위로 0.5% 이상 치솟은 이력이 있음 (진짜 눌림목인지 확인)
3. 이번 봉 저가가 20EMA에 닿음 (±0.3%)
4. 해당 봉이 하이킨아시 양봉이면 다음 봉 시가에 진입

**진입 B — 골든크로스 추세 추종**
- 10EMA가 20EMA를 상향 돌파 + 하이킨아시 양봉 → 다음 봉 시가 진입

**청산**
- 손절: 진입 시점 직전 10봉 최저가 (스윙 로우)
- 익절: 손절폭의 1.5R (파라미터 조정 가능)
- 추세 이탈: 종가 2봉 연속 20EMA 하회 또는 데드크로스 시 청산

**자금 관리**
- 1회 리스크: 계좌의 1%
- 수수료: 편도 0.05% 반영

## 파일

- `heikin_ashi_strategy.py` — 전략 코어 (하이킨아시 변환, 시그널, 백테스트 엔진)
- `backtest.py` — 업비트 5분봉 백테스트 CLI
- `live_signal.py` — 실시간 시그널 체크 CLI
- `requirements.txt`

## 실행

```bash
pip install -r requirements.txt

# 백테스트 (KRW-BTC, 3000봉 ≈ 10.4일)
python backtest.py --market KRW-BTC --candles 3000 --risk 0.01 --rr 1.5

# 실시간 시그널 체크
python live_signal.py --market KRW-BTC
```

## 백테스트 결과 (솔직 기록)

업비트 실데이터 기준, 수수료 편도 0.05% 반영:

| 조건 | 거래 | 승률 | 평균 R | 수익률 |
|---|---|---|---|---|
| BTC 5분봉 10일 | 69회 | 22% | -0.50R | -29.5% |
| ETH 5분봉 10일 | 85회 | 21% | -0.51R | -35.5% |
| BTC 5분봉 30일 | 218회 | 23% | -0.43R | -60.9% |
| BTC 4시간봉 83일 | 16회 | 31% | -0.04R | -0.8% |
| ETH 4시간봉 83일 | 22회 | 23% | -0.19R | -4.2% |

해석:
- 5분봉에서는 수수료(왕복 0.1%)가 평균 손절폭(0.35%)의 1/3을 갉아먹고,
  골든크로스 진입이 횡보 휩쏘에 반복적으로 털린다.
- 4시간봉(영상이 실제 시연한 타임프레임)에서는 눌림목 매수가 주 신호가 되고
  손익이 수수료 수준으로 수렴한다. 그래도 플러스는 아니다.
- 결론: 영상의 규칙을 글자 그대로 옮기면 현 상태로는 실전 투입이 어렵다.
  타임프레임 상향, 추세 필터(ADX 등) 추가, 손절/익절 규칙 개선이 다음 실험 과제다.

## 영상 분석에서 확인된 사실과 한계

- 확인: 하이킨아시 차트 종류 적용, EMA 길이 20, 10/20 더블선 결합, SK하이닉스·BTC 예시
- 한계: 영상에 진입·손절·익절 가격 마커가 없어 손절/익절 규칙은 실전 일반 기준으로 보완
- 한계: 제목은 5분봉 단타이나 예시 화면은 4시간봉·일봉. 타임프레임별 파라미터 최적화는 별도 검증 필요
